말로 지시하기

설정(⌘,)에서 "수혁아"로 음성 지시를 켜면 수혁이 "수혁아"를 기다립니다. 키보드에 손을 대지 않고 에이전트에게 일을 시키고 답을 들을 수 있습니다.

  1. "수혁아, 펠릭스 커밋해 줘"처럼 호출어 뒤에 에이전트 이름과 지시를 말합니다. 지시는 펠릭스의 세션으로 전달됩니다.
  2. 대답이 오가고 1분 동안은 호출어 없이 바로 말해도 됩니다. 이름을 빼면 마지막으로 말을 건 에이전트에게 갑니다.
  3. 에이전트가 답을 마치면 수혁이 읽어 줍니다. 누가, 어떤 요청에, 무엇을 했는지 먼저 말하고 결론을 짧게 전합니다. 여러 에이전트가 동시에 끝나면 차례로 읽습니다.
  4. "그만"이나 "고마워"라고 하면 대화가 끝납니다.

창 위쪽의 대화 모드를 켜면 호출어 없이 계속 듣습니다. 대화창 입력칸에서는 마이크 버튼으로 받아쓰기를 합니다. 이름은 발음이 조금 달라도 알아듣습니다. 예를 들어 "필릭스"라고 들려도 펠릭스로 처리합니다.

음성 인식은 가능하면 Mac 안에서 처리하고, 답변 요약은 Mac 안의 Apple 모델이 합니다. 읽어 주는 목소리는 Supertonic 모델(약 400MB)을 처음 쓸 때 내려받으며, 받는 동안에는 macOS 기본 음성으로 읽습니다. macOS 설정의 받아쓰기가 켜져 있어야 하고, 처음 쓸 때 마이크와 음성 인식 권한을 허용해야 합니다.

Android 비공개 테스터 모집

Google Play에 정식으로 내려면 테스터 12명이 14일 동안 앱을 설치해 두어야 합니다. Mac이 없어도 체험 모드로 참여할 수 있습니다.

  1. 테스터 그룹에 가입합니다. Google 계정으로 로그인한 뒤 그룹 가입을 누릅니다.
    테스터 그룹 열기
  2. 같은 계정으로 테스트 참여 페이지를 열고 테스터 되기를 누릅니다.
    테스트 참여하기
  3. 참여 페이지의 링크로 Google Play에서 수혁을 설치합니다. 가입 직후에는 스토어에 반영되기까지 몇 분 걸릴 수 있습니다.
  4. 14일 동안 앱을 지우지 말아 주세요. Mac이 없다면 첫 화면에서 Mac 없이 둘러보기를 누르면 예시 세션으로 모든 화면을 볼 수 있습니다.

불편한 점은 대화 입력창에 /피드백 내용을 적어 보내거나 GitHub 이슈에 남겨 주세요. 앱은 광고가 없고, 개인정보를 수집하지 않습니다. 개인정보처리방침

설치

Mac 앱을 먼저 설치합니다. 휴대폰 연결은 필요할 때 추가합니다.

Mac

  1. Homebrew로 설치합니다. tmux도 함께 설치됩니다. 
    brew install oyhoyhk/tap/suhyeok
  2. 실행합니다. 
    suhyeok
  3. Launchpad와 Spotlight에서 찾으려면 링크를 만듭니다. (선택) 
    ln -sf "$(brew --prefix)/opt/suhyeok/수혁.app" ~/Applications/수혁.app

Claude Code나 Codex CLI가 설치되어 있어야 합니다. Homebrew가 없다면 brew.sh에서 먼저 설치하세요. 새 버전이 나오면 사이드바에 업데이트 버튼이 생깁니다.

휴대폰

Android 앱은 비공개 테스트 중입니다. 테스터로 참여하면 Google Play에서 설치할 수 있습니다. 테스터가 아니라면 휴대폰 브라우저로 연결합니다.

  1. Mac의 수혁에서 설정(⌘,)을 열고 모바일 접속을 켭니다. QR 코드가 나옵니다. 2026년 10월 12일 이전에 수혁을 설치했다면 먼저 터미널에서 brew install cloudflared를 실행합니다.
  2. 휴대폰 카메라로 QR을 찍습니다. 브라우저에서 수혁 화면이 열립니다.
  3. Mac에 뜬 창에서 허용을 누르면 연결됩니다.

QR은 한 번만 쓸 수 있고, 연결된 기기는 같은 설정 화면에서 끊을 수 있습니다. Mac에서 수혁을 다시 실행하면 접속 주소가 바뀝니다. 이때는 휴대폰에서 QR을 다시 찍어야 합니다.

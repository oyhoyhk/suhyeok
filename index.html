핵심 기능

세션 1개 = 캐릭터 1명. 상태에 따라 길드홀의 다른 구역으로 걸어감

🏰

길드홀 월드

  • 모든 로컬 Claude Code·Codex 세션을 맵 한 장에 표시
  • 작업 중 캐릭터는 도구별 동작 — 편집=타이핑, Bash=망치질, 읽기=끄덕임
  • 호버 → 세션 제목·프로젝트·마지막 지시
  • 입력 기다리는 에이전트는 게시판에 모아 표시
⚔️

수혁 안에서 세션 운영

  • ⌘N → 에이전트·작업 폴더·첫 지시로 새 세션 시작
  • 내장 터미널에서 키 입력·단축키 그대로 사용
  • 전용 tmux 서버가 실행 → 앱을 꺼도 세션 유지
  • cmux·Orca·tmux 세션을 대화 기록째 옮겨 오기
  • 최근 7일 대화를 "이어서" 한 번으로 복귀
💬

NPC 대화창

  • 캐릭터 일러스트와 함께 답변·지시를 대화처럼 표시
  • 작성 중인 답변을 실시간으로 보여 줌
  • 권한 확인·선택지 메뉴는 빠른 키(↑ ↓ ⏎ Esc 1 2 3)로 응답
  • Esc로 작업 중단, ↑로 마지막 지시 불러오기
  • 모델·컨텍스트·5시간/주간 사용량 상태줄
🖥️

어떤 터미널이든

  • tmux·Orca·cmux는 터미널 화면을 직접 읽음
  • Ghostty·Warp·VS Code 내장 등은 대화 기록으로 자동 전환
  • 지시는 원래 터미널 세션으로 그대로 전달
🎙️

음성 지휘

  • "안녕 수혁아, ○○아 …" 호출어로 에이전트 지정 후 지시
  • 답변을 요약해 캐릭터 목소리로 읽어 줌
  • 답변 요약(Apple 온디바이스 모델)·음성 합성은 Mac 안에서 처리
📱

폰에서 지휘

  • Android 앱 또는 폰 브라우저로 지도·대화·지시 보내기
  • 작업 끝·선택 대기 알림 (Mac 알림 센터 + 폰)
  • QR 한 번 + Mac에서 허용해야 연결
💎

길드 · 결정

  • 일한 시간·끝낸 턴·커밋만큼 결정이 쌓임
  • 결정으로 용병 영입 (기본 8명 개방)
  • 캐릭터 마켓: 다른 사용자가 만든 캐릭터 구매·내 캐릭터 판매 등록 (운영진 승인제)
  • 게임 안 재화. 코인·현금화 없음
🛡️

로컬 우선

  • 세션 상태는 ~/.claude·~/.codex 로컬 파일에서 읽음
  • 외부 통신은 모바일 접속(켤 때만, Cloudflare 터널)·결정 정산·업데이트 확인뿐
작업 중 → 왼쪽 작업대응답 생성·셸 실행 중. 도구별 동작 + 머리 위 아이콘
대기 중 → 가운데 선술집응답 끝난 지 10분 미만. "…" 말풍선
휴식 중 → 오른쪽 라운지10분 이상 조용함. zzz (시간 변경 가능)

설치

Mac 앱이 본체. 폰은 Mac에 연결해 쓰는 리모컨

🍎

Mac — Homebrew

  1. 터미널에서 설치 (tmux 함께 설치됨) 
    brew install oyhoyhk/tap/suhyeok
  2. 실행 
    suhyeok
  3. Launchpad·Spotlight에 넣기 (선택) 
    ln -sf "$(brew --prefix)/opt/suhyeok/수혁.app" ~/Applications/수혁.app
  • 요구 사항: Apple Silicon Mac, macOS 14 이상, Claude Code 또는 Codex CLI
  • 업데이트: 새 버전이 나오면 사이드바에 "업데이트 설치" 버튼이 뜸. 직접 하려면 brew upgrade suhyeok
  • 0.1.1 이하 사용자는 한 번만 brew upgrade suhyeok 직접 실행
Homebrew가 없으면 brew.sh의 한 줄 명령으로 먼저 설치
🤖

Android 앱

  1. suhyeok-android-0.2.0.apk를 폰에서 내려받음
  2. 파일을 열고, 처음이면 "출처를 알 수 없는 앱 설치"를 브라우저에 허용
  3. Mac 수혁에서 설정(⌘,) → 모바일 접속 (외부 인터넷) 켜기 → QR 표시
  4. 폰 앱의 QR 스캔으로 Mac 화면의 QR을 찍음
  5. Mac에 뜬 허용 창에서 허용 → 연결 완료
iPhone 등 다른 폰: 3단계 QR을 폰 카메라로 찍으면 브라우저에서 같은 기능(지도·대화·지시)을 씀
QR은 한 번만 쓸 수 있고, 연결된 기기는 같은 설정 화면에서 언제든 끊을 수 있음
